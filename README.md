# 交通事故圖

純前端、單檔、無需安裝的交通事故現場繪圖工具，專為台灣警察勤務設計。

直接用瀏覽器開啟 `index.html` 即可使用，不需伺服器或網路連線。

---

## 功能

**車輛與機車**
- 小客車、貨車、公車、半拖車、全拖車、機車
- 車輛命名（A–F 或自訂）、車長車寬標記、定位標記

**路面標線**
- 實線、虛線、雙黃線、斑馬線、轉彎道、導引島、網格線
- 機車待轉區、停車格、箭頭（直行、轉向、三向）、分隔島

**量測工具**
- 基準點 + 基準線（距離量測）
- 尺寸線（自動偵測障礙物）
- 車輛定位標記、間距線

**其他**
- 自由文字框、路面標字、路段方向標示
- 消防栓、指北針、比例尺、紅綠燈、電線杆
- 手繪箭頭、圖片嵌入
- 事故資訊印章、車牌清單印章

**操作**
- 多圖層管理
- 復原／重做（最多 100 步）
- 縮放（0.1×–4×）+ 平移
- 格式刷（複製文字排版）
- 列印輸出（A4 橫向）
- 專案儲存至 localStorage，匯出／匯入 JSON

## 開發

原始碼分三個檔案，建置後合併為單一 `index.html`：

```
dev.html    ← HTML 結構
style.css   ← 樣式
script.js   ← 邏輯（約 9,800 行）
```

建置指令：

```bash
bash build.sh
```

詳細技術文件見 [`技術文件.md`](技術文件.md)。

---

## 比例尺

預設 1:100，A4 畫布（1123×794 px）對應實際 11.23m × 7.94m。
可調整比例尺範圍：1:50 至 1:500，切換時所有物件等比縮放。
